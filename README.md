# NUMdropper
NUMdropper is my first project on GitHUB.
Built as a hands on learning experience while exploring html,css,Javascript.
**Live site:** https://shyamlan-phygitals.github.io/NUMdropper/index.html
## ABOUT:
- NUMdropper is a browser based mini project/game that generates random numbers between 1 to 500(using Math.random()*501) and keeps track of your statistics..
- it can be accessed through a weblink(provided above) on both mobiles or computers.

## FEATURES:
- Maintain a running total of all generated numbers.
- Track the highest number generated.
- Automatically save those statistics using localStorage
- works directly in modern web browsers. so, installations required.

 ## TECH STACK USED:
HTML5,CSS3,JAVASCRIPT,WEB LOCALSTORAGE API.

## how to use:
- open the link mentioned above.(https://shyamlan-phygitals.github.io/NUMdropper/index.html)
- press ADD .
- your total and highest number are updated.
- Continue generating numbers and track your statistics.

## DATA STORAGE MECHANISM:
- this project uses browser local Storage to preserve statistics between visits.
- NOTE: statistics are stored separately on each browser and device.
